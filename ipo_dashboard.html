🔗 GitHub Connection

🔑 GitHub Token (to edit stocks from here)

Needed only to save stocks from this dashboard.
Stored only in your browser (localStorage) — never sent anywhere else.

How to get it:
1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click "Generate new token (classic)"
3. Tick repo scope → Generate → Copy the token here
